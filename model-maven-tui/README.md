# Model-Maven TUI

真实 CLI/TUI 联调可以使用统一入口运行（需要 Unix PTY 和已安装 PyTorch 的 Python）：

```sh
python3 scripts/verify_integration.py \
  --cli ../model-maven/target/debug/m-model \
  --tui target/debug/m-model-tui \
  --python /path/to/python \
  --output /tmp/model-maven-integration-result
```

输出目录必须不存在。用 `python3 scripts/verify_integration.py --list` 查看案例；可重复添加 `--case ID` 只跑相关案例，省略时跑完整套件。`--case-timeout SECONDS` 控制单案例上限。报告明确区分局部选择与完整套件，保存各案例日志；48/32 条件提交和输入重放还保留合成模型、TUI 回执及生成的变体，不保留临时输入快照。

报告在运行前后记录二进制摘要，以及两份仓库的 HEAD、已跟踪文件差异和非忽略未跟踪文件内容摘要；运行期间若这些前后证据不一致，结果为失败。来源读取不是原子快照，不覆盖 Git 忽略文件、嵌套仓库或在两次检查之间发生后又恢复的修改；输出目录自身不计入摘要。缺少 PyTorch 时只生成未完成报告。所有案例使用合成数据，其中冲突和旧版场景通过包装器模拟，不代表真人或生产环境验收。

TUI 对已纳入超时保护的同步只读 CLI 请求接收的标准输出限制为 32 MiB；超出时显示读取错误，可缩小查询或检查 CLI 兼容性。后台请求的报告上限为 8 MiB。为了避免在写入或训练操作中制造不确定的中断，这些限制不适用于所有带副作用的命令，也不覆盖未列入超时保护的同步查询。

创建自定义模型时，可在输入声明中用 `@native=text_encoder` 保留该编码器的原始输出，例如 `text:int64=?5,4;@native=text_encoder;@seam.fusion=components:fusion`。融合模块会收到未经自动平均或展平的输出；其他编码器仍使用默认处理。原始输出的形状或类型可能与默认融合和预测头不兼容，创建后应配置相应组件并运行真实前向。

新骨架创建后可在装配工作台选择 `encoder-output`，为某个编码器预览并保存 `native` 或 `flatten`。预览和保存都会运行代表批次；保存会核对配置和可用的已观察项目源码，并可选择要求输入内容与预览一致。早期生成的骨架需要用户手动增加 `encoder_output_modes` 参数，才支持此操作。

批次每次都变化时，可选择 `route+snapshot` 或 `encoder-output+snapshot`：预览捕获一次代表输入，保存时重放并校验该输入。界面会显示临时文件路径及清理结果；快照包含输入值，异常退出可能留下文件。

如果输出方式和融合组件必须一起更改，在装配工作台选 `patch`，在绑定字段同时填写 `fusion=components:flat;@output.text_encoder=flatten`。系统会对完整候选执行一次前向，再让用户确认是否一起保存；也可使用 `patch+snapshot` 捕获代表输入。

输入接线也可以和预测头等组件一起调整：例如在同一字段填写 `head=components:head8;@route.b_encoder=a`。这适合接线变化后特征维度随之改变、两项修改单独预览都会失败的情况。

在工作台打开“项目组件”，可用 `scaffold` 创建 Layer 或 Layer Edit Provider 扩展包，修改生成的 Python 和清单后用 `install` 构建、安装到项目本地并登记。构建可能执行包代码，默认隔离构建可能下载构建依赖；选择 `no` 使用当前 Python 环境中已安装的构建依赖。操作均需确认并在后台执行，完成后可 `test`，再在装配时选择该组件。安装不会自动绑定模型或修改所选 Python 环境；失败或回执丢失时先检查项目扩展存储和组件列表。

移除组件时先选择精确版本并用 `uninstall` 启动后台预览，刷新后用 `review` 检查影响并确认。被引用的组件需明确输入 `FORCE`；配置、变体和用户源码不会被自动修改，引用可能因此失效。

`m-model-tui` 是 `m-model` 的独立交互终端前端。当前入口包含盲文动画欢迎屏、模型结构检查、代表批次前向诊断和 Python/PyTorch 能力检查。

## 运行

在 Ghostty 中运行 `cargo run --release --locked -- --diagnosis-demo` 可使用 48/32 离线样例。按 Enter 进入诊断，方向键切换调用，`a` 对照末轴，`e` 预览修复，`y` 确认，再按 `1` 或 `2` 查看同一批次的通过或仍失败样例。`s` 可切换风格和操作预设，Tab 在图与详情之间切换。参数 `--diagnosis-case last-observed` 和 `--diagnosis-case snapshot-missing` 可查看证据不完整的场景。缺少匹配的结构快照时，界面直接显示调用证据，仍可用 `i` 查详情、`v` 看全文和 `a` 对照末轴。设置 `MODEL_MAVEN_REDUCE_MOTION=1` 可从静止的欢迎和诊断画面启动。

在调用详情按 `i` 可看报告、批次、输入输出、形状来源和源码位置。方向键或详情区滚轮可在已记录的输入间切换。在证据面板按 `v` 查看换行后的全文，方向键或滚轮逐行滚动，PgUp / PgDn 翻页，Esc 回到同一输入。按 `u` 从该输入追到生产者，Esc 回到同一份证据，恢复原图页和视角。行式模式用 `j` / `k` 选择，用 `b` 返回。旧报告里的来源仍可在全文查看，若改接已替换原边，追踪会说明当前图中没有这条观测连线。

第一段确认后，按 `n` 定位第二个调用，再预览和确认连线改接。预览中的虚线是候选路径。改接后可按 `x` 选一个缺失的来源端口，确认失败会保留当前图和草稿。按 `l` 查看按版本排列的离线回执，按 `?` 查看当前面板的操作。

确认后按 `r` 打开重验样例菜单。`3` 演示记录在目标调用后截断，`4` 演示不同批次的报告被拒绝，可对照两份报告的批次标识和上一次有效结果。载入有效报告后按 `c`，图会聚焦同一个失败端口。宽度达到 96 列时，两个报告并排展示，窄窗口一次显示一份。用 `c`、上下方向键、PgUp / PgDn 或详情区滚轮切换前后证据，快捷键预设也可用 `j` / `k`。按 `v` 可滚动查看双方完整证据，包括原批次、提交版本和目标端口。Esc 先回到所选的对照页，再回到原来的回执和视角。

加上 `--diagnosis-case twin-merge` 可验收两个合并节点的同名端口。按 Enter 进入工作台，再按 `e`、`y` 把 `net.merge_a.in[0]` 的末轴从 32 改到 48。按 `n`、`e`、`y` 改接 `net.merge_b.in[0]`。按 `x`、`y` 验证失效来源被拒绝，按 Esc 退出草稿后用 `l` 查看 v2 和 v3 的回执。

从模块树或单层视图进入预览时，图会定位到目标输入所在的张量流。确认成功后，图回到本次修改的输入端口。矮窗口可以先读回执，再按 Tab 切到图查看高亮。无色模式也能靠端口上的菱形辨认本次改动。取消草稿会恢复原来的图层级、连线、相机和缩放。预览里按 `v` 可查看完整目标、原值和候选值、原始报告、权重影响及拒绝原因。按 Esc 返回确认画面。

加上 `--diagnosis-case crossed-ports` 可查看同一对模块间交叉的两条张量线。80×30、关闭动效时，在第 27 列、第 8 行重复点击，或在选中后按 `w`，可分别检查两对端口。交叉点下方的线留有缺口，选中的线会移到上方，共用端口的线仍从同一点出发。端口和所属层的边缘共用一格时，悬停和点击会优先选择端口的连线。悬停模块本体可查看形状、堆叠和参数量，缺少记录的数值显示 `?`。双击模块本体可聚焦模块，Esc 回到原连线和视角。

加上 `--diagnosis-case large` 可打开千层样例。按 Tab 聚焦图，`u` 从失败端口追到另一组的生产者，Esc 恢复原页和相机，`b` 返回分组总览。选中生成组后按 Enter 展开，`h` 切换到组内张量流。在详情中继续预览时会重新定位故障证据。

窗口太矮时，Tab 在全图和详情之间切换。从图中按 Esc 返回详情，也可以继续原来的草稿。详情区滚动切换调用，图内滚动缩放。演示编辑区接收点击和键盘焦点，区内的滚动和翻页键不会翻动上方图。

在诊断主画面按 `m` 返回欢迎页，再按 Enter 继续查看上一次选中的调用。当前图版本、缩放、草稿和重验结果都保留在本次会话中。空格切换本次会话的动效，欢迎页和诊断台沿用同一个选择。在行式模式输入 `m` 后按 Enter。

在诊断主画面的图或详情中，关闭编辑预览后可用 `s` 进入设置。`1` 切换视觉风格，`2` 切换操作预设，`r` 恢复默认值。返回后继续查看原来的连线、视角和重验结果。在图上按 `?` 查看图操作。快捷键预设增加 `g` 切换面板、`j` / `k` 选择、`o` 展开，详情用 `p` 预览，`t` / `f` 载入通过或失败样例。

在受限终端可用 `cargo run --locked -- --diagnosis-demo --line-mode` 进入行式模式。这条命令可在 macOS、Linux 和 Windows 的 shell 中使用。每个按键后按 Enter，`j` / `k` 切换调用，`b` 返回或取消，`?` 查看当前操作，`q` 退出。行式视图显示当前图版本和选中的连线，证据、草稿和回执随实际终端宽度换行。重定向时从标准输入读取命令，结果写入标准错误流，宽度可用 `COLUMNS` 指定。40 列全屏预览也会分行显示编辑目标、前后值或来源，以及权重影响。

真实 CLI 工作台也支持 `cargo run --locked -- --line-mode --cli /path/to/m-model`；Windows 和不支持全屏控制的终端会自动使用行式交互：输入菜单按键并回车，可检查与列出模块、查看诊断、定位调用，以及预览 Linear 输入维度。输入 `b` 可退出表单或取消预览；从批次表单返回时保留已输入的模型工厂。工作台内容写入标准输出，欢迎提示和输入提示写入标准错误。工作台的“设置 → 语言”提供跟随系统、English、简体中文、繁體中文，选择立即生效并保存，下一次启动的欢迎页也使用该选择；`--lang en`、`--lang zh-cn` 或 `--lang zh-tw` 可覆盖当次启动的设置。后端 CLI 返回的诊断与用户代码输出可能仍使用其原始语言。

真实工作台首页按 `/` 搜索操作（行式模式输入 `/` 后回车），可按操作名称、说明、内部名称或当前键位查找。全屏模式会随输入预览匹配数量和结果，回车后可选择操作；`!` 标记当前不可用的操作，选择后可查看所需条件。搜索使用当前操作预设和自定义键位，取消后回到原菜单焦点。

真实工作台会在当前会话中分别保留最近诊断和最近预览。默认键位用 `9`、`0` 回看，快捷键预设用 `h`、`u`；运行环境检查不会覆盖它们。回看的预览不会重新执行 CLI，也未重新验证；重新检查模型或运行诊断会清除旧预览，切换模型会清除旧诊断。

模型和批次表单会带入本次会话最近使用的值，批次只在模型及其工厂参数相同时带入。在模型工厂输入框键入 `:model-params` 可设置 JSON 参数对象，例如 `{"width":32}`；检查、诊断和候选预览会使用同一组参数。切换模型或修改参数后，旧结构、诊断和批次设置不会自动匹配到新模型。全屏输入框可用 `Ctrl+U` 清空，再按 Enter 使用项目默认值；行式模式按 Enter 保留显示的当前值，输入 `:default` 使用项目默认值。

首页显示当前会话选择的模型和批次；尚未选择与使用项目默认值分别标注。窗口较矮时菜单跟随方向键滚动，`↑ …` 和 `↓ …` 表示还有未显示的选项。

首页按 `o` 可打开另一个项目目录，相对路径以当前项目为基准。目录有效后重新读取项目状态，并清除旧项目的模型、批次、报告、结构和预览；打开当前目录或输入无效路径时保留当前上下文。Esc 返回，行式模式输入 `b` 返回。

在尚未配置的项目中，首页按 `n` 可填写模型工厂和可选的批次工厂。工作台先调用 `m-model init --dry-run` 展示将创建的文件和入口；这一步不会导入或验证工厂。阅读预览后明确选择保存，才会调用 `m-model init` 创建配置。取消或直接回车不会保存。

首页根据项目状态显示下一步，首次进入或切换项目后默认选中该操作，直接按 Enter 即可执行；普通返回首页时保留上一次操作的焦点；切换或重新选择变体后重新推荐下一步。行式模式在首页直接回车也会执行显示的下一步。按 `c` 可查看项目检查的 CLI 结果和错误，并用 `r` 重试；启动时可通过 `--cli PATH` 或 `MODEL_MAVEN_CLI` 指定 CLI。重试时如果配置版本已改变或无法核对，工作台会清除旧会话证据并提示原因。

对同一显式模型完成结构检查和诊断后，首页按 `k` 可逐次选择已记录的调用并定位到结构图。列表保留调用序号；无法唯一匹配的调用显示原始详情。检查快照尚未与调用核对身份时会明确提示，未记录的张量来源不会画成连线。

从调用列表进入图后，按 `l` 返回列表；再次进入时会恢复该次调用的视角、缩放、展开层级和布局。不同调用分别保存视图，即使它们属于同一个共享模块。重新检查或诊断后会清除这些视图。

工作台设置中的 `4. 变体` 从 CLI 读取项目变体列表；可选择可读且名称唯一的变体，或选择 CLI 默认。选择或重新选择都会清除当前会话的结构、诊断和预览，之后检查、诊断及预览携带该变体名称。列表仅表示读取结果，不验证或固定版本；CLI 默认模式下，修改预览可能使用已有的 `working` 变体，界面会提示这一点。

回看具名变体的结构、诊断或预览前，工作台会通过 `variant show` 比较 CLI 报告的版本字段。版本变化或无法读取时，工作台清除会话证据并提示重新检查；CLI 默认模式无法做此比较。该检查仅比较 CLI 返回的元数据，不是完整性验证或原子版本固定，仍无法排除检查后的并发变更、模型代码变化或批次变化。

真实 CLI 的 Linear 预览报告中按 `d` 打开差异视图。两侧按完整路径对齐检查报告和候选报告中的模块，`n` / `p` 同步翻页，窄屏用 Tab 切换；`+` / `-` 仅表示模块只出现在某份报告中，`~` 表示报告字段不同，重复路径标为歧义。这些标记不证明结构实际增删：检查快照尚未与预览基准版本核对，报告未提供的连线也不会被补造。按 `v` 查看验证、权重效果及来源说明。

当 CLI 报告复用历史探测证据时，报告、调用列表和图中会提示本次没有执行新的前向；仅在 CLI 明确返回 `evidence_cache.status=reused` 时显示。在批次工厂输入框键入 `:options` 可设置批次绑定（auto、envelope、single、args、kwargs）和可选数据集指纹。指纹是用户维护的数据身份声明，数据变化时必须更新；CLI 还要求稳定样本 ID 才能复用证据。输入 `:batch-params` 可设置批次工厂的 JSON 参数对象，例如 `{"size":48,"split":"train"}`；这些参数会传给诊断及候选前向预览。输入 `:mode` 可选择 `eval` 或 `train`，诊断和预览使用相同请求模式；报告分别显示 CLI 实际观测到的模式；模式与请求不一致时暂停基于该诊断的预览，候选验证模式不一致时标明未验证请求模式。未报告或无法识别模式时明确显示无法核对。空对象清除参数，取消保留原值。同一模型和批次的再次诊断会沿用设置，切换模型或批次不会自动带入。 重复诊断时，只有两份报告都提供非空且标记为稳定的批次 ID，界面才会比较它们；否则显示无法核对。批次 ID 匹配依赖所声明的指纹和样本 ID，复用缓存时也会提示本次没有重新前向。

调用列表会按 CLI 提供的调用 ID 显示执行嵌套，可选择任一记录进入对应模块；这是函数执行关系，不能当作张量生产者关系。上级 ID 缺失、重复、顺序异常或执行身份冲突时标为未知，较深层级以 `…N` 标出深度。筛选支持调用、上级调用、前向、探测和批次 ID。

调用列表中按 `/` 可筛选模块路径、实例或调用 ID、嵌套输入输出路径、张量类型和形状；也可搜索保留的探测报告和最近一次其他 CLI 报告中的诊断码、消息或提示，结果标明报告来源，打开后可查看原始报告，不推断诊断与调用的关联。筛选结果保留报告中的原始序号。空查询清除筛选，Esc 取消输入。报告调用记录或单次调用的筛选范围被截断时，列表会给出提示。

若查询唯一匹配所选调用中完整记录的一个输入，全屏模式会直接打开该输入证据；多个输入匹配时可按路径、形状和类型选择。输入记录截断时，列表会说明只覆盖已记录项，并要求明确选择。输入证据页按 `l` 返回调用列表，再次进入可恢复上次查看的输入。

启动时会显示项目配置检查状态。真实工作台运行检查、诊断、环境检查或预览时，会在标准错误显示当前操作和适用的模型、批次、目标；结果仍写入标准输出。Unix 上的检查和预览类 CLI 请求可按 `Ctrl+C` 取消，默认等待上限为 120 秒；可通过 `MODEL_MAVEN_TUI_CLI_TIMEOUT_MS` 调整毫秒数，设为 `0` 可关闭超时但仍可手动取消。取消或超时后先请求 CLI 中断并等待最多 11 秒清理，再结束本次 CLI 进程组；独立进程组中的后端 worker 需由 CLI 配合停止。已确认的保存会提示等待完成，期间的 `Ctrl+C` 不会中断保存。Windows 也接入了超时、运行中 Ctrl+C 和已确认保存的保护，使用 Windows 作业对象清理只读命令的进程树；Windows GNU 交叉构建后，已在 Wine 中验证大输出、超时后子进程清理、模拟取消、保存保护和模拟 CLI 报告链路；真实 Windows Terminal 的控制事件与原生运行仍待验收。

同一个显式模型和批次的诊断重试超时或取消后，旧报告会标为上一次诊断并保留；需重新诊断后才能继续定位或预览。

在失败详情、修复预览或重验结果按 `a`，上方画布会切到末轴截面。两条截面共用起点和比例。较长一侧的末端用虚点投到另一侧，其他轴缺证据时截面留开口，末轴未知时显示 `?` 和断开的起点。`+`、`-` 和图内滚轮同时缩放两条截面，Esc 恢复原来的图、相机和草稿。具体维度与报告来源在下方详情，行式模式用等比例字符条显示。

### 查看 Drifting 源码

工作台没有已检查的模型结构时，「3D 模型结构」默认打开内置 Drift-L 样例。在 Ghostty 中也可直接进入。内置图由仓库附带的源码与预设生成并编入程序，源码位置对应 `fixtures/drifting/models/generator.py`。 [Drifting 官方实现](https://github.com/lambertae/drifting/tree/8861066430db11d2fb0858d042c7845b99df49f1)

```sh
cargo run --release --locked -- --demo-graph
```

首屏显示 `DitGen` 的噪声、条件分支、`LightningDiT` 主干与输出。方向键选择，Enter 或双击展开当前层。进入 `blocks` 才建立当前预设的 block 实例，进入单个 block 才建立其调制、注意力、残差和前馈节点。展开子图时会复用上一级和已有同级布局。页键可以在重复 block 之间翻页，Esc 返回上一级。选中节点后可在详情阅读 `models/generator.py` 的对应行号或范围。现有适配覆盖生成器主干，生成器内部关注的路径包括 Q/K/V、QK 归一化、RoPE、Softmax、SwiGLU 和输出重排。

按 `w` 选择连线，`u` 追到生产者，`d` 追到消费者。展开相连的模块时，短箭头标记跨层端口，选中的条件张量可从 `DitGen.conditioning` 一直追到单个 block 的 `adaLN`。Esc 返回追线前的页、缩放和选中端口。

选中连线时，详情区显示两端的源码位置。两份官方预设的 `noise_embeds` 可展开为 32 个坐标，再展开某个 `coord_XX` 可追踪标签切片、Embedding 和逐次累加。

在注意力里，`reshape_qkv` 把投影拆为 Q、K、V 共享的五轴张量。展开 `rope` 可分别追踪 Q、K 的旋转，展开 `head_axes` 可查看换轴以及 K 在矩阵乘法前的轴交换。详情中的 `B` 和 `N` 分别表示批次大小与 token 数，头数和每头宽度取自预设。空间不足时缩写共有的路径前缀，保留连线两端的端口编号。

`--drifting-demo` 也是内置样例的入口。通过 `--drifting-source` 导入源码目录时，使用 `python3` 3.9+ 静态解析。下面的命令可以直接在本仓库运行。导入自己的副本时，传入包含 `models/generator.py` 的目录。默认读取该目录下的 `configs/gen/latent_sota_L.yaml`。用 `--drifting-config` 指定其他预设时，相对路径以当前工作目录为准。

```sh
cargo run --release --locked -- --drifting-source ./fixtures/drifting
```

查看 Drift-B 时指定仓库附带的官方预设。Drift-B 有 12 个 block，默认 Drift-L 有 24 个。两个预设共用 `models/generator.py`，展开某个 block 内的 `Attention` 后可以查看它自己的 Q/K/V 和矩阵运算。

```sh
cargo run --release --locked -- --drifting-source ./fixtures/drifting \
  --drifting-config ./fixtures/drifting/configs/gen/latent_sota_B.yaml
```

静态图依据源码调用位置和配置建立连线，运行时形状与实际分支保持未知。配置中的宽度无法按注意力头数均分时，导入会报告校验错误和预设路径。 [Drift-B 官方预设](https://raw.githubusercontent.com/lambertae/drifting/8861066430db11d2fb0858d042c7845b99df49f1/configs/gen/latent_sota_B.yaml)

已有新版 `m-model` 在 PATH 时，在模型项目目录运行已构建或安装的 `m-model-tui`。从源码运行时可分别指定 CLI 可执行文件和项目目录。

```sh
cargo run --locked -- --cli ../model-maven/target/debug/m-model --project ../model-maven
```

按 Enter 进入工作台，按 `q` 退出。以 CLI 仓库为项目目录时，选择前向诊断，输入模型工厂 `examples.complex_acceptance.contract_repair:build_model` 和批次工厂 `examples.complex_acceptance.data:changing_batch`，可查看仓库自带的 48/32 维错配及最后调用位置。所用 CLI 的 Python 环境需要 PyTorch。

真实 probe 失败且最后观测到的调用为 Linear 时，返回工作台可选择「预览 Linear 输入维度」，输入候选 `in_features` 后查看 CLI 的只读预览和验证结果。预览摘要和差异视图会列出 CLI 报告的受影响别名；字段缺失或不完整时明确提示，便于识别共享层的影响范围。预览要求 CLI 执行候选前向；默认会重新调用批次工厂，样本可能与原探测不同。有检查快照时，预览目标必须与其中唯一的 Linear 路径匹配；若不匹配或存在歧义，需重新检查。没有快照时仍可按调用报告的路径只读预览。路径匹配不能证明身份或版本一致，检查快照与预览基准版本尚无法核对。当模型、批次、模式、输入内容和变体基准满足条件时，可明确确认提交；提交后自动核对新变体并重验，最近回执可从工作台重新查看。

兼容的 CLI 会在预览中报告变体基准 token，摘要会显示该 token；旧 CLI 或无法识别的报告会显示基准不可用。这个 token 只标识变体 JSON，不固定模型源码或批次，详情见[变体基准契约](docs/variant-base-contract.md)。

兼容 CLI 对受支持的前向输入提供内容指纹；诊断和实际执行的候选前向都提供有效指纹时，预览摘要会显示内容相同或不同。超出支持范围、旧报告或复用的候选证据会显示无法核对。指纹不会保存或重放原批次，也不核对模型或运行环境；支持范围见[输入内容契约](docs/batch-content-contract.md)。

需要重放诊断时的输入时，在批次工厂表单输入 `:snapshot` 并选择 `on`，再填写批次工厂。兼容 CLI 会在私有临时文件中保存受支持的输入值，预览、提交和重验使用该快照；默认关闭。不支持的输入或旧 CLI 会明确提示。正常退出、切换项目或变体及完成提交后会清理临时目录；异常退出可能留下文件，快照没有加密。该功能重建输入值与结构，不固定源码、权重或运行环境，详情见[输入快照契约](docs/input-snapshot-contract.md)。

构建两边并准备好 CLI 的 PyTorch 环境后，可运行 `python3 scripts/verify_real_batch_content.py` 验证内容比较，或运行 `python3 scripts/verify_real_snapshot_replay.py` 在隔离项目中验证快照重放及清理。

对同一显式模型先执行结构检查，再运行 probe。失败后返回工作台可选择「定位最后观测调用」，在已检查的结构图中打开匹配模块。模块详情显示调用序号、观测输入形状及检查快照中的输入维度。按 `a` 以共同的比例对照末轴，用 `+`、`-` 或滚轮缩放，按 Esc 恢复结构图和原视角。继续按 Esc 可逐层返回。图中的结构来自检查报告，前向连线以报告提供的证据为准。

在支持的 Unix 终端中，工作台和设置页使用方向键移动焦点、Enter 选择，数字或字母快捷键也可直接使用。设置页可以切换布局和操作预设。输入表单使用 Enter 继续、Esc 返回。报告条目可用方向键选择，报告与详情用 `n` 和 `p` 翻页，`b` 或 Esc 返回。终端能力受限时可使用行式菜单。

输入表单支持左右方向键、Home / End、Ctrl+A / Ctrl+E、Delete 和退格。支持括号粘贴的终端会在粘贴期间保留输入焦点，换行转换为空格，按 Enter 提交。

图宽度至少 36 列且鼠标捕获启用时，顶部 `[-][+][<][>][^][v][R][E]` 可单击：前两项缩放，方向键在二维平移、立体视图旋转，`R` 重置当前层级，`E` 展开所选模块。按下后拖离按钮会取消。 图中选中模块且没有选中连线或端口对时，按 `v` 打开模块详情，滚动查看完整路径、类型和已提供的实例、参数、来源及别名信息；别名超过 64 项时提示省略数量。调整窗口后保留阅读位置，返回后恢复原视角与选择。

全屏菜单中 Tab / Shift+Tab 可前后移动焦点；图与详情、图与编辑器或差异视图的两侧可用两者切换。输入框和搜索继续处理文字，详情弹层保留自己的焦点。如果终端没有发送 Shift+Tab，可用方向键移动菜单焦点，双面板可用 Tab 或屏幕显示的单键切换。

在工作台设置中选择 `3. 工作台键位`，可为当前操作预设调整菜单动作的单键；冲突会指出占用该键的动作，`b` / `q` 及设置、退出入口保留。两个预设的工作台键位分别保存，图内和离线诊断的键位继续使用对应预设。全屏编辑时清空输入可恢复该动作的预设键，行式模式输入 `:default`；设置中的恢复默认会同时清除两套菜单自定义键位。

设置中的“叙事”风格提供带导航提示的对话式布局。首页的“3D 模型结构”打开终端内的立体视图。图获得焦点后按大写 `L` 开关布局编辑模式，开启后可按住左键拖动模块，端口和连线会随之移动。模块与连线落在同一单元格时，编辑模式优先选择模块；再次按 `L` 返回普通模式，优先选择连线。拖动空白处可旋转视角。鼠标悬停可查看层信息。滚轮或触控板双指上下滚动可在指针处缩放，也可使用 `+` / `-`。双击某层或选中后按 Enter 可聚焦并查看其子层，Page Up / Page Down 或 `[` / `]` 翻页，Esc 或 `b` 返回上一级。上下键选层，左右键旋转。在本次查看中，返回同一图层级时会恢复拖动后的布局。图上按 `r` 恢复当前层级的默认布局和视角。按大写 `T` 可释放或重新启用鼠标捕获，释放后可使用终端自身的选字和滚动。

张量视图用单线从输出连到输入。同一输出扇出的线从一个端口起步，汇入不同输入的线各自落在对应的端口。箭头表示方向，断线与交叉符号表示形状错配，虚线表示形状信息不足。画布只保留模块名、分组和拓扑。悬停在连线上会并列展示两端形状，翻页边缘用箭头标出跨页端点。连线挤在同一格时，可重复点击或按 `w` 依次选中；大写 `W` 打开候选列表，用方向键、滚轮或 Page Up/Down 浏览，Enter 或单击确认；按 `s` 在指针/当前页候选和已加载范围的所有已记录投影间切换，两个列表各自保留焦点。当前页没有可见连线时，`W` 仍可打开范围列表并标注此状态。按住后拖离条目或窗口失焦会取消该次点击。候选分别显示输出与输入端口，跨层显示的底层连线也分行显示两端；悬停其他对象时已选连线的主要证据仍会保留。图获得焦点时，按 `u` 或 `d` 沿选中线追到源端或目标端，按 `h` 在张量流与模块树之间切换。

张量流中按 `z` 可切换二维分层原型与立体视图。二维视图使用相同节点、端口和连线，采用正交折线，宽屏从左向右排列，窄于 60 列时从上向下排列。拖动空白处或使用左右方向键平移。两种视图分别记住缩放和平移，再次按 `z` 恢复立体视角。离线诊断先用 Tab 把焦点移到图。二维原型沿用当前分页，复杂跨组路由与任务对比仍在开发中。

分层或爆炸视图同一页出现多个同名模块时，标签会补上能区分它们的父级路径；狭窄分支会压缩成唯一的路径提示（例如 `qkv#6`）。选中模块后按 `v` 查看完整路径。

Drifting 的空间、二维和两档爆炸画布样稿见[图预设对照](docs/graph-preset-review.md)，其中分别保留了像素和无色字符捕获。样稿用于检查信息层级，不代替真实终端或用户任务验收。

图获得焦点时按大写 `M` 打开当前已加载模块组的端口矩阵。真实检查图进入后即可使用图快捷键；从矩阵选中跨页连线并返回时，图中保留两个端口编号。行代表输出端口，列代表输入端口。`=` 表示形状对齐，`×` 表示错配，`o` 表示连线的形状未知，`!` 表示同一单元格的连线状态混合，`-` 表示快照明确声明该端口对无连线，`?` 表示连线状态未知。crossed-ports 和 twin-merge 离线样例提供明确的无连线声明；真实检查报告和 Drifting 图尚未提供完整覆盖声明，其未记录端口对仍显示未知。拓扑修改后旧的无连线声明会失效。行首箭头、列标和竖线标出当前单元格的行列，无色彩时也可辨认。方向键或滚轮移动，Page Up/Down 翻页，`n/p` 按行列顺序循环跳到已记录的错配单元格；分组混合单元格会选中其中一条错配连线。Enter 或单击选择单元格；按住拖离、窗口失焦或尺寸变化会取消本次鼠标选择。选中未知或明确无连线的单元格后，图中列出两个端口及证据状态，不添加连线；按 `u` 或 `d` 可分别查看输出端或输入端，按 Esc 返回该端口对；按 `v` 可滚动查看完整端口路径与证据状态。分组单元格需展开后才能选择具体端口对。同一单元格包含多条底层连线时，用 `w` 或重复单击切换。按 `r` 按模块折叠输出行，按 `c` 折叠输入列，`g` 同时切换两者。分组显示记录的连线、错配、消费者数量和已覆盖端口对；未覆盖组合仍标记为未知。 按 `a` 浏览行列索引，用 Tab 切换输出行和输入列，方向键、滚轮或翻页浏览；Enter 或单击定位到矩阵，Esc 或 `a` 取消并保留原单元格。索引遵循当前分组，长路径优先显示末尾与端口编号；按 `v` 可滚动查看完整模块路径和分组中的各个端口，窗口缩放后保留阅读位置。展开和返回图时保留所选底层连线，包括原图页以外的连线。

本地已构建 TUI 和相邻 CLI，且 CLI 使用的 Python 环境安装 PyTorch 时，可运行 `python3 scripts/verify_real_pair.py`，在隔离项目中回放真实 CLI 的长路径端口证据和具名 Sequential 顺序。`MODEL_MAVEN_TUI_BIN` 和 `MODEL_MAVEN_CLI` 可覆盖两个二进制路径；脚本使用伪终端，不能替代原生终端走查。具名 Sequential 的报告字段与兼容边界见[顺序契约](docs/sequential-order-contract.md)。

当顺序声明与 CLI 的实例别名能够唯一核对时，多个注册位置会在图中分别显示；选中模块时可看到它们共享的 CLI 实例标识。该标识只在对应检查报告内有效。

共享模块的调用报告可能列出多个注册别名，却不指出实际经过了哪一个。此时诊断报告、调用列表和定位图会提示路径未知；图中首先匹配的路径只是查看结构的入口，不能证明本次调用经过该位置。

按 `/` 搜索模块路径、类型、已加载端口或图操作，例如 `head.in[0]`、`matrix` 或 `切片`；也可从图操作帮助打开。定位真实 CLI 的最后观测调用后，还可搜索输入路径或诊断码，例如 `kwargs.mask` 或 `FORWARD_FAILED`，分别跳到该输入证据或报告原文中的诊断。方向键选择结果，Enter 执行或跳转，Esc 保持原视角。命令面板也提供故障路径和离线修复差异入口；缺少调用证据或预览时会说明前置条件。真实 CLI 的修复差异仍从预览报告按 `d` 打开。端口结果逐条显示已记录的连线及其另一端；未记录连线的端口可单独选中，图中显示完整端口名和状态未知。跳转到其他结果后，返回历史可恢复该端口焦点。Drifting 源码图还可以搜索折叠的模块和端口，例如 `block_07.attention.qkv` 或 `block_07.attention.reshape_qkv.out[0]`。未加载的端口结果按源码作用域列出已知消费者；选择后仅按需展开目标路径，并核对端口和连线。长路径会保留末尾，便于区分消费者。

诊断图中按大写 `F` 查看当前调用的局部故障路径。方向键切换有记录的输入，形状标明观测或声明，末轴使用共同尺度。来源未知时路径在边界停止；不同调用的来源与总览冲突时仍以当前调用的记录为准，并标出总览的差异。`v` 打开调用证据，真实 CLI 报告可查看收到的 JSON 原文；方向键和 PgUp/PgDn 滚动，Esc 返回路径。`F` 或 Esc 返回原视角，再次打开会保留当前输入。定位真实 CLI 报告的最后观测调用后也可以打开该视图；报告未提供上游连线时会显示来源未知。

故障路径有足够空间时，若同一报告将输入接线的接缝唯一映射到当前模块，还会显示模型自述或配置中的声明。它不代表实际观测到的数据流，也不会自动画成观测边；共享路径不明确和未提供映射的情况仍显示为未知。新骨架会自述默认接线，旧骨架及普通用户模型需自行提供兼容的声明。

真实报告中的位置参数、关键字参数和嵌套容器按输入路径逐项显示，张量附有数据类型与观测形状；报告截断时也会显示截断边界。Linear 的声明输入维度只与其直接输入比较，其他输入的预期保持未知。

离线修复样例进入预览、提交或重验状态后，可按大写 `D` 查看同一目标的前后差异。宽终端并排显示，窄终端用 Tab 切换；`v` 查看报告、批次、回执和拒绝原因，Esc 返回。真实 CLI 的 Linear 输入维度预览结果中按 `d` 也可查看已检查结构与候选结构；连线和权重影响只显示 CLI 已报告的信息。

模块显示为有间距的颗粒切片。默认、紧凑和叙事三种风格共享端口布局，各自定义配色、颗粒、分隔线、焦点标记和提交反馈时长。扩展外观时在 `src/graph/appearance.rs` 配置这些属性。报告中的堆叠数优先，精确维度、头数和权重形状在详情区查看。每个输入和输出按文档中的端口顺序投影到切片上，已提交连线和编辑预览共用该投影。操作预设在 `src/graph/offline.rs` 将按键映射到语义动作，当前按键也用于页脚和帮助。

立体图按 `x` 可循环切换三档切片间距，状态行在展开时显示 `1/2` 或 `2/2`，端口和连线随模块投影更新。进入具有张量流的模块组后，展开状态会将已加载的实际子模块沿纵向分段排列；同层分支较密时节点会缩小以减少遮挡，超出可用宽度时会按分支分页，状态行显示当前范围，可用 PgUp / PgDn 或 `[` / `]` 切换。跨页连线以续接标记显示，端口详情仍可查看完整路径。重复块可按页选择并继续进入，切片用于展示单个模块；间距表示展开程度，张量维度请以详情为准。离线诊断中的图需要先获得焦点。

小型编辑样例包含分流与汇合，两个并行算子共用一列，翻页以列为单位。检查报告中，直接子模块按连续数字编号列出的 `Sequential` 使用声明顺序绘制静态连接，`Linear` 的权重矩阵只用于比较末轴。其他模块按报告显示层级与可用维度。图中几何比例为示意。

## 两个仓库的职责

- CLI 仓库负责公开命令、JSON 协议、项目配置、Python Worker 和模型/训练操作。其行式交互可由 `m-model` 直接启动。
- TUI 仓库负责屏幕、交互和视觉。真实数据通过参数化子进程调用 `m-model --json --no-interactive` 获取。每条命令以所选项目为工作目录，TUI 检查报告版本并呈现 CLI 的诊断。
- 当前接线使用协议 v1。两库分别构建、安装和验收。模型检查及 probe 会由 CLI 加载项目代码，probe 的证据缓存等文件行为也由 CLI 管理。

两仓库的对接任务和验收入口统一记录在 Model-Maven 后端仓库的 `todo.json`。并排检出时见[总计划](../model-maven/todo.json)。[工作台设计稿](docs/workbench-mockup.html)展示首页、前向诊断和修复预览的视觉方向。

### 接入离线诊断页面

`src/diagnosis.rs` 的 `Fixture::load` 提供结构快照、调用报告和预览及重验样例，运行时通过 `--diagnosis-case` 选择。`Snapshot::resolve` 先核对报告对应的快照，再用模块 ID 或唯一别名定位层。`CallId.invocation` 区分共享层的多次调用。`Evidence` 保留观测、声明或预览来源。共享层的同一输入端口只创建一次。各次调用的来源一致时可以映射到同一条图连线，形状各自在调用详情中保留。来源冲突时，在各次调用的证据里查看对应来源，该输入端口的修改入口会关闭。

`src/graph/offline.rs` 的 `Action` 根据阶段决定详情动作，`Shortcut` 为同一组导航事件提供备用键。两者都用于帮助和提示。扩展预设时，在 `src/workbench.rs` 保留持久化标识，再补齐详情动作与图导航，并核对设置、帮助和草稿等上下文的键位。编辑预览使用 `GraphDocument` 中的端口 ID 和基础版本，确认后的图与回执使用同一个新版本。离线偏好读取时，缺失或未知的风格、键位分别回退到默认，另一个有效选项继续生效。保存时保留原配置里的其他字段。

PTY 测试覆盖无色动画、Enter 交接、离线诊断与连接模拟 CLI 的失败路径。离线测试遍历三种风格、两套键位与三种颜色模式，分配到三种窗口尺寸与中英文，验证来源、取消、确认、重验和设置保存失败后的回退。受限终端另跑六种风格与键位组合，在 40 列完成两段编辑和一次拒绝，再切换到 80 列读取重验对照，核对回执及退出后的输入模式。真实 CLI 的能力另有联动验收。

此前的代码快照在 Apple Silicon macOS 分别使用 Rust 1.85.0 和 1.94.0 通过全量 release 测试；当前代码使用 let-chain，声明的最低 Rust 版本为 1.88。此前还用 Rust 1.94.0 对 `x86_64-pc-windows-msvc` 和 `x86_64-unknown-linux-gnu` 完成了包含测试目标的交叉编译检查。`cargo test --locked --test diagnosis_line` 可验证行式入口在 CRLF 输入、输出重定向和三种语言下的追线、返回欢迎页、确认到 v2 和 v3、拒绝第三段及原批次重验。Windows 与 Linux 终端上的实际操作仍待验收。

输入路由回放发送 SGR 鼠标事件 `CSI < 64 ; 列 ; 行 M` 和 `CSI < 65 ; 列 ; 行 M`，分别模拟向上和向下滚动，也单独发送 PgUp、PgDn 及横向滚轮事件。48×17 字符与像素回放检查图和详情切换时是否保留草稿及缩放。触控板手势产生的实际事件由原生窗口走查记录。

Apple M5 字符裁剪压力对照使用 100×23 画布，循环绘制三条穿出视口约 800 至 1,000 个单位的长线。11 轮 release 测量中，每 20,000 次笔画的中位时间为完整步进 92.05 ms、跳步裁剪 6.51 ms。两条路径的可见盲文位图逐格一致。短线、反向线和深度遮挡另由 `clipped_strokes_match_a_crop_of_the_full_depth_tested_line` 回归覆盖。
