# Model-Maven

Model-Maven is an early-stage CLI and terminal workbench for constructing deep-learning models. The repository contains the [backend](model-maven/) and [terminal interface](model-maven-tui/).

The npm distribution provides `m-model` and `m-model-tui`. Python and model-framework environments are managed by the user. See each component's README for setup, capabilities and limitations. Native platform packages are tested for installation and startup; this does not certify all model training or hardware configurations.
